# Value Proposition Canvas Delta

Purpose: Spark evidence-to-fit gate. The canvas blocks are model-known.

## Sequence

1. Build the Customer Profile first from Field, Voice, analytics, support, or clearly labeled assumptions.
2. Rank jobs, pains, and gains by user evidence, not implementation convenience.
3. Map each proposed product/service element to a ranked job, pain, or gain.
4. Remove or defer offering elements with no evidence-backed match.

## Fit Gate

A proposal may claim problem-solution fit only when at least one specific pain reliever or gain creator maps to a top-ranked, evidence-backed customer need. The canvas does not prove product-market fit or business-model fit.

## Required Output

| Customer evidence | Rank | Offering response | Expected measurable change | Confidence |
|---|---:|---|---|---|

Also include the source JTBD, unmatched top needs, unsupported offering elements, validation experiment, and explicit out-of-scope items.

## Routing

- Missing customer evidence -> Field or Voice.
- Unmatched offering scope -> Void.
- Adoption validation -> Experiment.
- Business-model economics -> Helm.

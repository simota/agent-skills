# Crazy 8s Delta

Purpose: Flux `crazy8` interaction and output contract. The ideation method itself is model-known.

## Protocol

- Restate the seed in one sentence and declare one divergence axis.
- Generate exactly eight short, complete, distinguishable variations in one turn.
- Change a different attribute on the declared axis for each variation; keep other dimensions roughly fixed.
- Include one or two deliberately unusual options to expose hidden constraints.
- Ask the user to select `1-3`; generation without convergence is incomplete.

If the user needs looser or multi-axis exploration, route to `scamper` instead of weakening the eight-variation contract.

## Summary Contract

```markdown
## Crazy 8s Summary
- Seed: [one sentence]
- Axis: [one axis]
- Variations: [numbered 1-8]
- Picks: [1-3 selected items]
- Revealed preference: [pattern across picks]
- Decisive question: [next uncertainty]
- Suggested next: [recipe or skill]
```

## Routing

- Deepen one pick -> Flux `propose`.
- Stress-test one pick -> Flux `steelman`.
- Choose among picks -> Magi.
- Feature-shaped pick -> Spark or Scribe[unified].

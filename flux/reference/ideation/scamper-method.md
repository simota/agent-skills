# SCAMPER Delta

Purpose: Flux `scamper` dialogue and convergence contract. The seven SCAMPER lenses are model-known.

## Protocol

- Restate the seed and select all seven lenses or a justified subset.
- Run lenses separately; produce `1-3` concrete, testable, differentiated variations per lens.
- Skip a lens that produces only relabeled versions of another lens.
- Pause after a small lens batch for user selection; do not dump twenty-one undifferentiated ideas.
- Converge selected variations into a candidate, decisive question, or explicit open lenses.

Useful subset routing:

| Situation | Start with |
|---|---|
| Generic idea | Adapt / Modify / Reverse |
| Suspected bloat | Eliminate / Substitute / Put to other use |
| Cross-domain expansion | Put to other use / Adapt / Combine |

## Summary Contract

Include the seed, lenses run, strongest variations with their originating lens, optional hybrid, decisive question, open lenses, and suggested next step.

## Routing

- Feature-ready variation -> Spark.
- Formal choice -> Magi.
- Stress test -> Flux `steelman`.
- More rapid divergence -> Flux `crazy8`.
- Packed hybrid -> Void for scope review.

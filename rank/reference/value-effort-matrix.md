# Value-Effort Matrix Delta

Purpose: Rank `value-effort` facilitation contract. The 2x2 quadrants are model-known.

## Protocol

- Define value, effort, and the high/low thresholds for this decision before placing items.
- Score the axes independently; do not lower value because delivery is hard or inflate effort because value is disputed.
- Place independently before reveal to reduce anchoring.
- Discuss high-variance items; do not re-litigate stable clusters.
- Treat quadrant labels as a first-pass triage, not a complete ordered backlog.

## Required Output

| Item | Value evidence | Effort evidence | Position / quadrant | Variance | Next action |
|---|---|---|---|---|---|

Include the axis definitions, thresholds, outliers, unresolved assumptions, and a diagram or coordinate table that can be reproduced.

## Routing

- High value / low effort -> Sherpa for decomposition.
- High value / high effort -> RICE, WSJF, or CoD for ordering.
- Low value / high effort -> Void for necessity review.
- Persistent placement disagreement -> Magi.

Reject median-as-threshold defaults, unlabeled axes, and precise coordinates unsupported by evidence.

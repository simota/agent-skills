# Chain Reference Index

Every `reference/` file `chain` owns, and the condition that makes it worth
reading. `chain/SKILL.md` keeps only the shared-contract rows and a pointer here.

**Read this when** you need a reference and the Recipe registry did not already
name it, or when scanning what this skill can consult at all.

|------|-------------------|
| `reference/intake-checklist.md` | You are running a new-skill intake audit and need the full per-item procedure |

| `reference/bundled-artifact-review.md` | You are auditing bundled scripts, binaries, or external resources referenced by SKILL.md |

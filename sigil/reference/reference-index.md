# Sigil Reference Index

Every `reference/` file `sigil` owns, and the condition that makes it worth
reading. `sigil/SKILL.md` keeps only the shared-contract rows and a pointer here.

**Read this when** you need a reference and the Recipe registry did not already
name it, or when scanning what this skill can consult at all.
